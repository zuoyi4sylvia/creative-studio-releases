# Creative Studio

Creative Studio 是一款原生 macOS 创意工作台，集中管理图片、视频生成及素材迭代。任务与生成文件保存在本地目录，模型服务通过用户自行配置的 API 密钥调用。

[下载最新版本](https://github.com/zuoyi4sylvia/creative-studio-releases/releases/latest) · [查看历史版本](https://github.com/zuoyi4sylvia/creative-studio-releases/releases) · [反馈问题](https://github.com/zuoyi4sylvia/creative-studio-releases/issues)

## 系统要求与安装

- Apple Silicon（M 系列）Mac，macOS 14 或更高版本；暂不支持 Intel Mac。
- 联网用于调用模型服务、下载生成结果及检查更新。生成需要可用的 API 密钥和对应模型额度，费用与可用模型由服务提供方决定。
- 从最新 Release 的 **Assets** 下载 `Creative-Studio-版本号-arm64.dmg`，打开后将 **Creative Studio.app** 拖入 **Applications（应用程序）**，再从应用程序启动。不要直接在 DMG 中运行。
- 也可下载 `arm64.zip`，解压后将 App 放入应用程序。GitHub 自动提供的 **Source code** 附件不是应用安装包。

当前安装包采用 ad-hoc 签名，尚未使用 Apple Developer ID 签名或完成 Apple 公证，首次安装可能出现 macOS 安全提示。仅从本仓库的 Releases 获取安装包；发布附件提供 `SHA256SUMS.txt` 供校验。Sparkle 更新签名不能替代 Apple 公证。

## 功能介绍

### 创意：图片与视频生成

- 输入提示词、选择模型和生成参数，支持一次提交多份产物；任务提交后显示排队及生成占位卡片。
- 图片尺寸支持预设与自定义，生成数量可选 1～10；视频可设置画幅比例、时长和分辨率，实际能力取决于所选模型。
- 参考素材支持点击选择、拖放和 `⌘V` 粘贴；支持图片和视频参考，合计最多 10 个，具体组合受模型及生成模式限制。
- 视频首尾帧模式提供独立的首帧、尾帧上传位置；全能参考模式可使用适配模型支持的参考素材。
- 产物显示可辨认的任务与产物 ID，方便定位和反馈；详情支持左右方向键切换。
- 产物卡片右键可删除、复制和复用参数；选择模式支持单击加选/减选及拖动框选。

### 迭代：重复素材处理

| 工具 | 用法 |
| --- | --- |
| event图 | 上传一张参考图，选择模型，按设置中的三个场景提示词和参数分别创建任务。 |
| 推广图改尺寸 | 上传一张或多张图片，自动识别已有尺寸；勾选缺少的目标尺寸，按配置的提示词创建任务。 |
| 抠图 | 上传图片、选择模型，输出透明背景或纯色背景；纯色可使用颜色选择器。 |
| 视频改尺寸 | 上传参考视频，选择目标尺寸及模型；自动读取参考时长作为默认值，支持修改生成时长和分辨率。 |
| 视频本地化 | 预留入口，暂未开放。 |

迭代任务保存在本地，右侧历史列表显示预览缩略图；支持修改标题、查看记录、再次生成和删除任务及其本地文件。

## 快速开始

1. 打开右上角齿轮 **设置 → API 与密钥**，配置并保存模型服务 API 密钥。当前对接服务为 [new-api.upupup.today](https://new-api.upupup.today)，可查看 [API 文档](https://new-api.upupup.today/docs) 和 [模型广场](https://new-api.upupup.today/pricing)。
2. 在 **创意** 中新建或打开工作区。一个工作区对应一个本地目录，用于保存任务和生成结果。
3. 选择图片或视频，填写提示词、选择模型与参数，需要时加入参考素材，点击生成。输入提示词后按 **回车** 提交，**Shift + 回车** 换行。
4. 在上方任务卡片查看进度。完成后点击预览；通过“访达中显示”定位实际文件，或复用参数继续创作。
5. 使用 **迭代** 时，先选择左侧工具，上传参考素材，检查参数后点击开始。批量改尺寸工具会列出缺少的尺寸，可自行勾选本次生成目标。
6. 如需调整批处理规则，打开 **设置 → 迭代配置**，配置场景、提示词和目标尺寸。新安装带有默认配置，保存的个人配置在升级时优先保留。

## 本地存储与数据

- 创意工作区和迭代存档目录可在界面中选择，任务信息、参考素材副本及生成文件保存在对应目录。
- 在访达中移动导出的产物后，App 会使用本地保留的预览副本展示。需要备份或迁移时，请同时保留工作区、迭代存档和 App 的本地数据；预览不能代替原始素材备份。
- 调用模型时，提示词与所选参考素材会发送给配置的模型服务，生成结果会下载到本地；这不是离线生成工具。
- 本仓库仅提供应用下载、更新信息和使用说明，不包含用户 API 密钥、工作区、参考素材或生成记录。

## 应用内更新

- 支持更新的旧版可从应用菜单 **检查更新…** 或 **设置 → 应用更新** 获取新版；更早的版本请先手动安装最新版本。
- 默认每天自动检查 GitHub Releases，可在设置中关闭。2.2.2 起，启动时也会静默检查；发现新版时，右上角版本号显示红点与 **有更新**。
- 点击版本号可查看版本说明，并选择 **下载并更新…**。选择稍后、查看说明或更新失败均不会清除提示，重新打开 App 后仍保留，安装对应或更高版本后自动清除。
- 更新由用户选择下载安装；有生成或素材导入任务时会等待完成，并在安装重启前保存未提交的输入，重新打开后恢复。
- 更新包与更新源采用 Ed25519 签名校验，发布附件附带 SHA256 校验文件。

## 常见问题

**生成失败怎么办？**

先检查 API 密钥、模型额度，以及该模型是否支持当前参考素材、尺寸和时长。错误详情会显示在任务卡片或作品详情中；反馈时请附任务/产物 ID、App 版本和错误信息，不要提交 API 密钥或敏感素材。

**自定义尺寸如何提交？**

2.2.4 起，GPT Image 2 / 2.5 根据目标比例自动选择合法生成尺寸，界面显示“导出尺寸 → 请求尺寸”。请求宽高为 16 的倍数，比例限 1:3～3:1，每边最多 3840，总像素 655360～8294400。优先保持精确比例，无法精确表示时仅允许不超过 0.1% 的比例取整误差；范围内找不到尺寸则拦截。导出尺寸可与生成像素不同，符合比例的原图再缩放至目标像素。2.5 竖图不会固定为 2:3。

超出比例时在提交前提示，整批不会部分生成。合法参数并不保证第三方渠道按要求返回：当前 gpt-image-2 渠道出现过请求 1008×2800 仍返回 941×1672，长图会提前提示此风险；高于 2560×1440 像素量的请求提示实验范围。渠道原图返回后仍严格验收。

**修改尺寸会裁剪内容吗？**

2.2.3 起，图片按渠道原图验收：同一比例可缩放至目标像素；比例不符时标记“尺寸不符”，保存原图，不用透明补边、裁剪或拉伸来满足尺寸，也不会自动换尺寸重试。视频按完整画面适配目标画布，比例不同时可能出现黑边。画面主体和构图仍受提示词及模型输出影响。

**更新会替换我的工作区吗？**

应用更新替换 App 本体，已有的个人配置和本地素材目录继续保留。重要素材仍建议自行备份。
